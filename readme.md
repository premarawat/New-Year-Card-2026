# 🎉 New Year Card 2026

A clean and elegant **New Year greeting card** designed using **HTML and CSS**.  
This project focuses on modern UI design, proper layout, and clean styling.

---

## ✨ Features

- 🎆 Festive New Year 2026 theme  
- 🖼️ Image-based card design  
- 🎨 Clean and minimal UI  
- 📱 Responsive layout structure  
- 💡 Beginner-friendly code  

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**

---

## 📂 Project Structure
```
├── index.html # Main HTML file
├── style.css # Styling for the card
├── card.png # Card image / preview
├── readme.md # Project documentation
```

---

## 🚀 How to Run the Project

1. Download or clone this repository
2. Open the folder in **VS Code**
3. Open `index.html` in your browser  
   **OR**
4. Use **Live Server** extension for a better experience
